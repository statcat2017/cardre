## Build prerequisites and command

Build on Linux ARM64 with Rust, Node.js 22.22.2 or newer, npm, PyInstaller, and
Tauri's Linux development libraries (`build-essential`, `pkg-config`,
`libwebkit2gtk-4.1-dev`, `libgtk-3-dev`, `libayatana-appindicator3-dev`,
`librsvg2-dev`, `libxdo-dev`, and `libssl-dev`). From the repository root:

```bash
./scripts/build-sidecar.sh aarch64-unknown-linux-gnu
cd frontend
npm ci
npm run tauri -- build --bundles deb
```

## Interactive validation

The runtime check used Ubuntu 24.04 ARM64 with the package installed, plus
`tauri-driver`, `WebKitWebDriver`, `xvfb`, Openbox, `xdotool`, `unzip`, and
Node.js. It ran with a restricted child `PATH` (`/usr/sbin:/sbin`) and without
`CARDRE_CORS_ORIGINS`, confirming that the packaged app resolves its sibling
sidecar and supplies the Tauri CORS origin itself.

```bash
TAURI_DRIVER="$(command -v tauri-driver)" \
xvfb-run -a sh -c 'openbox --sm-disable >/tmp/cardre-openbox.log 2>&1 & exec node scripts/validate-linux-arm64-desktop.mjs'
```
