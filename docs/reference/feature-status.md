# Feature Status

## Governance

Governance and branch execution have been removed from the launch product. The
product is a single opinionated logistic scorecard engine; manual-binning
review remains available through the plans-scoped API.

| Area | Status |
|------|--------|
| Logistic scorecard | executable |
| Manual-binning review workflow | executable (ungated plans API) |
| Branch/champion/comparison | removed |

## Node Catalogue

See `docs/reference/node-catalogue.md` for the full flat production node
catalogue. Every registered node is executable; there is no deferred or
launch/deferred tier.
