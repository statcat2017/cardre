Changes made to the original UCI distribution for this bundle:
  - Renamed the file `german.data` to `german_credit.csv`.
  - Added a header row with descriptive column names (the original file
    has no header; see dataset README.md for the mapping).
  - Mapped the target column `class` from {1, 2} to {"good", "bad"} to
    match cardre's good/bad string convention for binary targets.
  - Column values are otherwise unchanged (categorical codes such as
    A11, A30, etc. are preserved as-is; see README.md for the code map).
