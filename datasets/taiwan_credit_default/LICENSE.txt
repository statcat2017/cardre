Changes made to the original UCI distribution for this bundle:
  - Converted the file `default of credit card clients.xls` (Excel) to
    `taiwan_credit_default.csv` (CSV, UTF-8) so it can be read without an
    Excel parser.
  - Dropped the `ID` column (a row identifier, not a feature).
  - The second header row from the Excel file (the "X1", "X2", ...
    aliases) was discarded; the descriptive column names were kept.
  - Column values and the target are otherwise unchanged.
